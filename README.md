# 🎟️ WinForms Ticketing Kiosk  
### 콘서트 티켓팅 시뮬레이션 프로그램

C# WinForms 기반으로 구현한  
**콘서트 티켓 예매 과정을 시뮬레이션하는 데스크톱 키오스크 프로그램**입니다.

실제 콘서트 예매 서비스의 흐름을 참고하여  
날짜 선택 → 좌석 구역 선택 → 좌석 선택 → 가격 확인까지  
티켓팅 전 과정을 단계별로 구현했습니다.

## 📝 프로젝트 개요

본 프로젝트는  
**콘서트 예매 과정을 실제 서비스와 유사하게 체험할 수 있도록 구현한 시뮬레이터**입니다.

좌석도 기반 좌석 선택 방식과  
좌석 등급별 가격 표시, 날짜 선택 기능 등을 구현하여  
실제 콘서트 티켓팅 흐름을 WinForms 환경에서 재현하는 것을 목표로 하였습니다.

## 🎯 프로젝트 목표

- 실제 콘서트 예매 서비스와 유사한 UX 흐름 구현

---

## 🛠 주요 기능

### ① 메인 화면
- 공연 정보 및 일정 선택
- 날짜 선택 후 좌석도 화면으로 이동

### ② 좌석 구역 선택
- 공연장 좌석도 기반 구역 선택
- 좌석 등급별 색상 구분 (VIP / 일반 / 시야 제한석)
- 구역 선택 시 해당 좌석 상세 선택 화면으로 이동

### ③ 좌석 선택
- 선택한 구역의 좌석을 버튼 형태로 시각화
- 좌석 선택 및 선택 해제 기능
- 이미 선택된 좌석 중복 선택 방지
- 선택 좌석 실시간 표시

### ④ 가격 정보 표시
- 좌석 등급별 가격 정보 제공
- 선택 좌석에 따른 가격 확인 가능
